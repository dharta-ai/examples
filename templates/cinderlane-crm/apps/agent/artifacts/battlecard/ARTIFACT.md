# Battlecard

Create a battlecard for a named opportunity and competitor.

Write the instance under `outputs/battlecards/<opportunity-id>/`. Include the
customer's stated criteria, verified competitor claims, Cinderlane strengths,
known gaps, discovery questions, and objection responses. Attach dates and
sources to claims. Keep unsupported claims out of the final card.

Use a passive Markdown entry for the default presentation. Use `type_id`
`battlecard` when designating the Artifact.
