# CRM operator

Use this skill for account research, pipeline reviews, follow-up preparation,
and task planning.

Start with the account timeline and current opportunity state. Separate facts
returned by tools from inferences. Record source IDs and timestamps in working
notes so another turn can refresh stale facts.

Draft messages before requesting a send. Show consequential CRM mutations to
the user when the tool policy requires approval. Use idempotency keys for every
write.

Prefer a durable Artifact when the output has an audience or will be revisited.
Use the account-plan, battlecard, or board-report recipe when it fits. Create a
bespoke Artifact when those recipes do not fit the work.
